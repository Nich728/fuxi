# UX checklist

Reference rules taken from UI/UX Pro Max (MIT, see `LICENSE`). Only the rules are used here, not its style, colour or font recommendations: Fuxi's look is set in `.interface-design/system.md`.

- `pro-rules.md`: app polish rules and the pre-delivery checklist. Run through it before calling a screen done.
- `quick-reference.md`: the full list of UX guidelines by category (accessibility, touch, layout, motion, forms, navigation).

When reviewing a screen, check it against `pro-rules.md` first, then run the `web-design-guidelines` skill.
